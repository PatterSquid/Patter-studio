PATTER STUDIO

To install:
1. Right click this zip and choose Extract All, then open the extracted folder.
2. Double click "Install Patter Studio".
   If Windows shows "Windows protected your PC", click More info, then Run anyway.
3. A Patter Studio icon appears on your desktop and in the Start menu. Double click it to open.

It opens in its own window using Microsoft Edge. It needs the internet for the map and fonts.

Updates and packs:
You only need to install once. Each time Patter Studio opens with an internet connection, it checks for a newer
version and for new add on packs (new places, props, moves and set pieces), downloads them and keeps them on this
computer. Without internet it simply opens the copy it already has.
Videos Claude builds for you arrive the same way: a small dot appears on the Project button, and they wait under
From Claude in the Project window until you open them. Packs and updates (also in the Project window) shows your
packs, lets you add a pack file by hand, and can take you back to the previous version if a new one ever misbehaves.

Your work (Project button):
Everything saves itself as you go. The Project button at the top holds all your clips, your templates, and New blank project.
History lets you roll back to an earlier version. Save file and Open file are for backups or moving a project to another computer.
Press ? in the app to see every keyboard shortcut.
